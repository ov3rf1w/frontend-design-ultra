# Report Templates

Use when the user asks for audits, review, final QA, or stakeholder-readable output.

## UI Audit

- Executive Summary
- Evidence
- Findings by severity
- Impact
- Fix recommendation
- Effort estimate
- Verification follow-up

## Awwwards Design Direction

- Strategy lane
- Page job and audience intent
- Conversion/trust spine
- Brandkit summary
- First viewport concept
- Signature move
- Section rhythm
- Asset plan
- Motion plan
- Mobile adaptation
- Risk/gate notes

## Pre-Build Design Plan

- Goal
- Page job
- Strategy lane and signature move
- Files/components
- Token/system changes
- Component/state changes
- Accessibility requirements
- Performance requirements
- Motion/3D fallback
- Verification steps

## Implemented Outcome

- Implemented result
- Changed files/components
- Preserved systems and intentional extensions
- Component/state behavior
- Accessibility and performance decisions
- Lint/type/test/build results
- Authorized browser evidence or `Needs Browser Verification`
- Remaining evidence gaps and residual risks

## Ship Decision

- Pass/Fail/Needs Review
- Creative Jury critique, kept separate from Shipping Gates
- Binary Shipping Gate results
- Evidence ids
- Route/viewport coverage
- Reduced-motion result
- Blocking issues
- Non-blocking polish
- Performance/accessibility risks
- Ship recommendation
