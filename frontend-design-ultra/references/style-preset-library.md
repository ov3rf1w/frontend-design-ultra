# Style Preset Library

Use these presets as deterministic visual doctrines. A preset is not a template; it is a constraint set that controls typography, composition, surface language, motion, and anti-patterns.

## Minimalist Editorial

Use when clarity, restraint, premium calm, or conversion focus matters.

- Typography: one expressive display face plus highly readable body; strong line breaks; generous leading.
- Palette: warm monochrome or restrained duotone; one accent only.
- Layout: macro grid, exact spacing rhythm, sparse components, no decorative filler.
- Surfaces: low shadow, subtle border, radius as system not decoration.
- Motion: small entrance and state transitions; no theatrical scroll unless one moment earns it.
- Avoid: sterile SaaS defaults, tiny gray text, generic bento clutter, decoration pretending to be premium.

## Industrial Brutalist

Use when the brand should feel technical, editorial, hard-edged, tactical, or high-confidence.

- Typography: condensed, mono, or grotesk contrast; large type pressure; clear data labels.
- Palette: hard contrast with one accent family; no rainbow accents.
- Layout: visible grid, asymmetric weight, rule lines, index systems, large counters.
- Surfaces: sharp radius or deliberate square geometry; strokes over shadows.
- Motion: snap, reveal, mechanical sequencing; no soft floaty ambience.
- Avoid: mixing industrial grit with unrelated luxury softness, weak contrast, random noise textures, overused cyber UI.

## Soft Premium

Use for hospitality, lifestyle, wellness, luxury-lite, personal brands, warm SaaS, or human-centered services.

- Typography: elegant display/body pairing; avoid novelty flourishes that harm reading.
- Palette: warm tinted neutrals, muted accent, depth through temperature not saturation.
- Layout: layered composition, editorial whitespace, tactile sections, careful image crop.
- Surfaces: soft elevation, controlled blur only when text remains readable, refined radius scale.
- Motion: gentle spring, parallax restraint, material-feeling reveals.
- Avoid: generic beige templates, glassmorphism soup, low-contrast text, decorative blobs, ornamental overload.

## Brandboard

Use for `/brandkit`, identity presentations, landing pages that need identity proof, or projects with weak brand inputs.

- Typography: show display, body, numeric/mono if needed, and forbidden fallback.
- Palette: base, paper/surface, ink/text, accent, state colors, gradient or texture only if meaningful.
- Layout: logo/construction panel, color panel, type panel, component panel, image panel, application proof.
- Imagery: define subject, crop, lighting, texture, proof role.
- Motion: mark reveal, section rhythm, component micro-motion, reduced-motion still.
- Avoid: logos without concept path, arbitrary palettes, moodboards without token handoff.

## Product Proof

Use for SaaS, dashboards, developer tools, apps, and conversion pages where trust depends on seeing the product.

- Typography: clear hierarchy, data labels, readable body, compact metadata.
- Palette: calm surfaces with high state contrast.
- Layout: product state first, workflow proof second, claims after evidence.
- Surfaces: cards/tables/charts have clear density rules and states.
- Motion: state transitions and guided walkthroughs, not ambient animation.
- Avoid: fake dashboard rectangles, marketing copy before product clarity, unsupported metric claims.

## Editorial Motion

Use for campaigns, portfolios, high-end landing pages, or Awwwards-style work when performance and accessibility allow it.

- Typography: kinetic but readable; display type participates in composition.
- Palette: strong art direction with stable token contract.
- Layout: chapters, object stages, mask reveals, image/text choreography.
- Motion: one signature move, transform/opacity priority, reduced-motion final states.
- Avoid: every element animating, blank pinned states, scroll hijacking, motion that hides content.
