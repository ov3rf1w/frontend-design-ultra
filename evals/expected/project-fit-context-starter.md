# Expected Output: Project Fit For A Context Starter

Must include:

- Classifies the input as a context starter, specification, or scaffold fragment rather than a runnable application.
- Separates installed/configured facts from declared/inferred stack intent.
- Does not claim that builds, tests, or browser QA ran when the required executable surface is absent.
- Recommends product integration through a versioned adapter or contract while keeping the portable skill and executable starter independently versioned.
- Maps project artifacts to brief, research, design contract, page/component spec, assets, and quality gates.
- Names missing execution contracts such as package manager, lockfile, framework config, preview, test harness, and static-export limitations.
- Preserves the inspected project unless implementation was explicitly requested.
